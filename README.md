# Intake Hero GTM Strategy Dashboard

A comprehensive Go-To-Market playbook for Home Services sales teams targeting 3–15 technician HVAC and plumbing shops.

## What's Inside

Eight interactive tabs covering:
- **ICP & Overview** — who to target, three win zones, discovery questions
- **Competitive Intel** — HousecallPro, ServiceTitan analysis with displacement plays
- **Channel Strategy** — six outreach channels with effort allocation
- **Personas** — three buyer profiles with pain points and hooks
- **Messaging & Talk Tracks** — two conversation modes with scripts
- **Outreach Sequences** — segmented email and call sequences
- **Partner Strategy** — co-sell and referral structures
- **Seasonal Playbook** — timing windows for peak urgency

## Built as a Personal Workflow Tool

This tool was built independently as an SDR productivity system. It contains no proprietary customer data—just GTM frameworks, ICP logic, and outreach methodology. Company name and specific product references have been anonymized per an employment agreement.

## How to Use

This is a React component. To run locally or deploy:
- Copy the JSX file into a React project
- Import and render as: `<IntakeHeroGTM />`
- No backend dependencies required

## Deploy to Vercel (30 seconds)

1. Fork this repo
2. Go to [vercel.com](https://vercel.com)
3. Click "Add New" → "Project"
4. Select this repo
5. Deploy

Live demo will be available at your Vercel URL.
